# Personal AI Job Agent

[English](README.md) · [Русский](README.ru.md)

Telegram-бот для поиска работы с независимыми профилями **Career-first** и
**Relocation-first**, хранением в PostgreSQL и подбором вакансий на основе
подтверждённых данных.

## Профили поиска

- **Career-first** ставит выше соответствие карьерной цели DevOps,
  Infrastructure и SRE.
- **Relocation-first** ищет по заданным ролям для переезда и повышает приоритет
  только при наличии подтверждённых сигналов о доступности работы и поддержке.
  Отсутствие сведений о визе или переезде остаётся неизвестным.
- Каждый активный профиль сканируется отдельно; сбой одного источника не
  останавливает остальные.

Среди подключённых публичных источников: HeadHunter, Remote OK, Arbeitnow,
Job Bank Canada, EURES и настроенные Telegram-каналы. Источники Грузии
(JOBS.GE и HR.ge) включаются, когда Грузия выбрана для профиля. Кандидат v3.5.7
добавляет Армению в список стран и публичный Greenhouse-источник компании
Lineate для выбранных рынков Армении и Грузии. Само наличие вакансии не
подтверждает визовую поддержку или помощь с переездом. См. [план развития](ROADMAP.md) и
[обзор международных источников](docs/developer/INTERNATIONAL_SOURCES.md).

## Безопасность и данные

- Автоматические отклики и приватные действия HeadHunter отключены.
- Бот не обходит CAPTCHA и не выдумывает право на работу, визовую поддержку,
  компенсацию переезда или зарплату, если подтверждений нет.
- Резюме обрабатывается в памяти с ограничениями на размер и извлечение текста.
  Бот показывает предварительный просмотр и сохраняет данные только после
  подтверждения.
- Безопасное обновление локального бота сохраняет тома PostgreSQL и хранилища:

  ```bash
  JOB_AGENT_COMPOSE_PROJECT=repo ./job-agent update
  ```
