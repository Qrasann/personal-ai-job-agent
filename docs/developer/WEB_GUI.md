# Private Web GUI (development)

The web workspace uses the existing PostgreSQL schema, owner account and scan service. It does not run Telegram polling; the bot can continue separately. The web process needs the same `DATABASE_URL`, `TELEGRAM_BOT_TOKEN` and `TELEGRAM_ADMIN_CHAT_ID` settings as the bot, plus a separate `WEB_GUI_TOKEN` of at least 24 characters supplied privately through the environment. Do not commit or print this token.

Install `requirements.txt`, set the environment, then run `python -m app.web`. The default listener is `127.0.0.1:8080`; `WEB_GUI_HOST` and `WEB_GUI_PORT` are optional. For a Compose rollout after release gates, use the separate `docker-compose.web.yml` overlay with a private `WEB_GUI_TOKEN` in the shell environment; it binds the web port only to localhost and uses the existing PostgreSQL service. Open `/login` and enter the web token. Keep the listener local. Production exposure and deployment require the repository release gates, including backup, compatibility, rollback and smoke verification. The standalone command must point only at an authorized database; never use the production database for development tests.

Dashboard reads owner statistics and the latest scan journal. Search calls the same `scan_for_user` path as `/scan`; its in-process status and durable summary are shown in the workspace. Jobs and Review read the owner's matches, with source-specific vacancy detail/evidence, save/skip and idempotent prepared-package actions. Jobs has separate below-threshold views for manual inspection; these preserve low-score reasons and do not label leads as Good. Profiles edits the target role and accepts owner-confirmed Candidate Facts with an explicit experience type and evidence. Sources toggles scan adapters per search profile. Relocation edits target countries and role queries and can enable the separate Career-first/Relocation-first search profiles. CV accepts PDF/DOCX/TXT up to 8 MiB, previews extracted text and proposed facts, and requires explicit save with or without selected facts; overlap choices default to keeping existing facts. The extracted text preview expires after 15 minutes and is memory-bounded. CV also stores manual text resumes. Applications shows the frozen package and status history in the browser, permits manual status updates, and offers full text export. No web action submits an external application.

Bot, scheduled and web scans share a PostgreSQL transaction lock for each owner. A second pass reports that a scan is active and does not start another source sweep. Process exit or cancellation releases the lock. This coordination does not change matching thresholds or send applications.

For immediate search through the existing Telegram bot, use `/parallelsearch on`, configure relocation roles with `/relocationroles warehouse, hotel staff` (replace these examples with the owner's actual choices), inspect `/settings` and `/sources`, then use `/scan` and `/scanstatus`. Review results with `/jobs career`, `/jobs relocation`, `/review` and `/applications`. The Telegram bot must already be running and configured; these commands do not establish that any source is reachable or useful.

Production preparation, smoke and rollback are specified in [WEB_GUI_ROLLOUT.md](WEB_GUI_ROLLOUT.md).
