# Project OS — AI Job Agent

Операционная система проекта: единый источник правды (Source of Truth) для передачи контекста между моделями (ChatGPT, Claude, Gemini), живыми разработчиками и CI/CD.

## Структура
text
docs/PROJECT_OS/
├── README.md               # Общая структура и правила навигации
├── AI_INSTRUCTIONS.md      # Обязательные инструкции для любого ИИ-ассистента
├── CURRENT_STATE.md        # Актуальное состояние системы прямо сейчас (Ground Truth)
├── HANDOFF.md              # Протокол передачи управления следующему разработчику/ИИ
├── TASKS.md                # Активная задача, критерии приемки и локальный бэклог
├── ROADMAP.md              # Долгосрочные этапы развития проекта
├── DECISIONS.md            # Архитектурные решения (ADR)
├── ARCHITECTURE.md         # Схема компонентов, пайплайн и схема данных
├── DEVELOPMENT_LOG.md      # Хроника изменений и релизов
├── KNOWN_ISSUES.md         # Известные особенности, воркэраунды и ограничения
└── IDEAS.md                # Каталог гипотез и будущих улучшений


## Правило работы с контекстом
1. Чат — временная рабочая сессия. Репозиторий — долговременная память.
2. При смене сессии или модели сначала читаются `AI_INSTRUCTIONS.md`, `CURRENT_STATE.md` и `HANDOFF.md`.
3. После завершения любой функциональной задачи обновляются `CURRENT_STATE.md` и `DEVELOPMENT_LOG.md`.
