# PROJECT_OS

Portable handoff context for Personal AI Job Agent.

Repository state is the source of truth. Chat history is supporting context only.

Read in this order:
1. BRIEF.md (short current checkpoint; read after AGENTS.md; older snapshots under history/)
2. [Canonical project roadmap](../../ROADMAP.md)
3. TASKS.md (start with its active priorities, do not read historical log wholesale)
4. ARCHITECTURE.md
5. DECISIONS.md
6. KNOWN_ISSUES.md
7. HANDOFF.md (historical; read only relevant entries)
8. DEVELOPMENT_LOG.md
9. AI_INSTRUCTIONS.md

Every release updates code, tests and PROJECT_OS together.
Historical snapshots are retained in `history/`; consult them only when a
specific past decision or result is needed. Git and current BRIEF supersede old
branch/runtime/pending claims.
