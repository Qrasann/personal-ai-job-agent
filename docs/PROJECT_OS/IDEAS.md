# IDEAS & EXPERIMENTS

## 1. LLM-валидация неявных требований
- Использовать легковесную модель для анализа текста вакансий на скрытые ограничения (например, требование строгого нахождения в РФ при заявленном full-remote).

## 2. Telegram Channel Watcher
- Подключение Telethon/Pyrogram для мониторинга каналов с вакансиями (DevOps Jobs, Remote IT) в реальном времени.

## 3. Экспорт аналитики в Obsidian / Notion
- Формирование еженедельного дайджеста рынка труда по стеку (динамика зарплат, частые требования).
