# Scope — Personal AI Job Agent v3.2

## Цель сейчас

Один персональный агент для поиска выбранных IT-ролей из России:

1. российские вакансии;
2. international remote, доступный кандидату из РФ;
3. relocation-вакансии;
4. Telegram-посты с вакансиями;
5. адаптация резюме и сопроводительного;
6. позже — автоматизация общения с recruiter/recruiter-AI там, где источник предоставляет законный и стабильный интерфейс.

## Не цель текущей версии

- полноценный SaaS;
- billing;
- массовая регистрация пользователей;
- обход CAPTCHA/anti-bot;
- скрытая браузерная автоматизация, нарушающая ограничения площадки.

Архитектурный запас под multi-user и дополнительные страны остаётся, но не является приоритетом MVP.
